# 기획자 전달 자료 안내

## 먼저 확인할 자료

1. `01_product-brief.md`  
   구현 목적, 네 화면, 자동 배정안 생성·승인, 상태, 예외 상황과 결정할 질문을 정리한 주 문서다.

2. `prototype.html`  
   Edge 또는 Chrome으로 바로 열 수 있는 화면 샘플이다. 확정 디자인이 아니라 정보 구조와 업무 순서를 확인하기 위한 자료다.

## 필요할 때 확인할 참고자료

3. `02_current-data-flow.md`  
   현재 `sb-work`에서 어떤 화면과 데이터가 사용되는지 설명한다.

4. `03_database-handover.md`  
   운영 DB와 저장소 SQL의 차이를 정리한 기술 참고자료다. 데이터 구조 협의가 필요할 때 개발자와 함께 확인한다.

## 이번 기획에서 우선 확정할 것

- 자동 배정안 생성일과 복제 기준
- 배정안 승인 단위와 예외 항목 처리 방식
- 업무 배정자·작업 담당자·결제 담당자의 권한
- 노션 확인과 결제 보완 요청 기준
- 정산 대상, 요청 횟수, 금액 계산, 견적서 필수 여부
- 상태별 버튼, 안내 문구, 알림 방식
- 1차 출시 범위와 후속 범위

## 요청사항

프로토타입의 디자인을 그대로 재현하기보다 기존 `sb-work`의 디자인 체계를 유지한다. 기획자는 업무 규칙, 화면 정보, 상태 변화와 예외 처리를 확정하고, 개발자는 그 결과를 기준으로 DB와 구현 구조를 설계한다.
